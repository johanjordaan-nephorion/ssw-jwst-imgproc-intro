# ssw-jwst-imgproc-intro

An introductory project exploring image processing with imagery from the James Webb Space Telescope (JWST) image library.

## Overview

This project:

1. Pulls raw images from the JWST image library.
2. Combines multiple images using a color ramp.
3. Renders the resulting composite image.

The main output of this project is a presentation walking through the process and the resulting composite imagery.
